# 연분 緣分 — 사주가 이어주는 인연

사주 궁합 기반 데이팅 앱. Expo(React Native + TypeScript) 구현.
기획: [`../docs/product-spec.md`](../docs/product-spec.md) · 백엔드 스키마: [`../supabase/`](../supabase/)

## 실행

```bash
npm install
npx expo start        # QR 코드를 안드로이드 Expo Go 앱으로 스캔
npx expo start --web  # 브라우저에서 바로 확인
```

## 구현 범위 (P0 전부)

- **온보딩**: 본인정보(PASS 목업) → 12지시 출생시간 선택("몰라요" = 삼주·정확도 75%) → 사주팔자 카드
- **사주 엔진** (`src/lib/saju/`) — 순수 TS, 결정론:
  - `manseryeok.ts` 만세력: 생년월일시 → 사주팔자 (일주는 1970-01-01=신사일 기준, 절기는 평균일 근사)
  - `compat.ts` 궁합: 오행 상생·일간(천간합)·지지 합충·띠·음양균형 5요소 가중합 0~100 + 풀이 문장
  - `fortune.ts` 운세: 오늘의 일진 × 내 일간의 십신 관계로 데일리/주간 운세 생성
- **홈**: 궁합 가중 정렬 카드덱(오늘의 인연 3명), 신호(50)·상세 풀이(30, 1회 열람 후 영구)·패스, 추가 열람(20)
- **운세**: 오늘의 운세 확인 = 엽전 +5 (7일 연속 +50), 주간 연애운 유료(30), 내 사주 카드
- **관심함**: 받은 신호 연결, 상위 궁합 조회자 블러 티저(해제 60), 조회자 목록(구독 유도), 내 매칭
- **채팅**: 매칭 후 1:1 대화 (데모: 상대 자동 응답)
- **피드**: 고민상담/사주풀이/자유/셀소, 글쓰기·좋아요
- **마이**: 스토어(패키지 5종), 미션, 내 사주 정보(출생시간 2회 수정 제한), 데모 초기화
- **엽전 경제**: 전 소모/획득이 `src/lib/economy.ts` 상수로 관리, 모든 과금은 2단 확인 시트

## 검증

```bash
npx tsc --noEmit                    # 타입체크
npx tsx scripts/verify-saju.ts      # 만세력·궁합·운세 엔진 검증 (공개 만세력 기준값 대조)
npx expo export --platform web      # 번들 확인
```

## 알려진 한계

- 절기는 평균일 고정 → 경계일(±1일) 출생자는 앱이 "절기 경계 출생" 안내를 표시. 프로덕션은 만세력 DB로 교체
- 데이터는 로컬(AsyncStorage) + 시드 12명. Supabase 이관 시 `../supabase/README.md` 참고
- 스토어 결제는 데모(즉시 충전). 실서비스는 IAP + 서버 원장으로 대체
