# 연분(緣分) — 사주 × 데이팅 서비스 설계서 v0.1

> 벤치마크: 글램(glam) 앱 스크린샷 16장 (2026.08) · UI/UX 제외, 기능·운영 구조만 대상
> 작성: 2026-08-27

**핵심 테제**: 글램의 정렬축은 외모 티어(절대 서열), 연분의 정렬축은 궁합 점수(상대값).
티어는 하위권의 이탈을 만들지만, 궁합은 누구에게나 "천생연분인 상대"가 존재한다.

---

## 1. 운영 루프 — 글램 4대 루프의 치환

| 글램 루프 | 연분 치환 | 요지 |
|---|---|---|
| 평가 루프 (유저 별점 → 티어) | **궁합 정렬 루프** | 평가 노동 없이 생년월일시가 정렬 원료. 서열화·외모 논란 원천 제거 |
| 수익 루프 (크러쉬·조회자·부스트) | **풀이 수익 루프** | 소모처의 무게중심을 글램이 팔 수 없는 상품(궁합 풀이·운세 리포트)에 |
| 신뢰 루프 (직장·학교·매력 인증) | **사주 신뢰 루프** | 인증 체계 이식 + 생년월일 PASS 인증값 고정으로 궁합 데이터 진위 보장 |
| 리텐션 루프 (피드 + 미션 + 무료 젬) | **운세 리텐션 루프** | 매칭 없어도 매일 열 이유 = 오늘의 운세. 콜드스타트의 해답 |

**설계 원칙**: 글램의 티어·실물 랭킹은 도입하지 않는다. 서열화 장치가 없다는 것 자체가 포지셔닝이다.

## 2. 탭 구조 (5탭)

글램 골격(홈·둘러보기·관심함·피드·마이) 유지, "둘러보기(평가)" 자리를 "운세"로 교체.

### ① 홈 — 오늘의 인연 (글램: 홈 카드덱)
- 필터(성별·나이·거리) 통과 유저를 **궁합 가중 정렬**로 노출하는 카드덱
- 카드마다 궁합 요약 배지: "궁합 87 · 상위 3%" + 한 줄 요약
- 인연 신호 보내기(엽전 소모 = 글램 크러쉬) / 패스
- 오늘의 인연: 자정 갱신, 고궁합 3명 무료 — 추가 열람은 엽전

### ② 운세 (글램의 평가 파밍 대체)
- 오늘의 운세(무료) — 확인 시 엽전 +5 = 데일리 출석 장치
- 주간 연애운 / 월간 운세 (요약 무료 · 상세 유료)
- 내 사주 카드: 사주팔자 요약 이미지 공유 → 오가닉 유입 채널
- 시즌 상품: 신년운세·토정비결 (P2)

### ③ 관심함 (글램: 받은·보낸 관심)
- 받은 신호 → 연결하기(무료) / 관심 없음
- 블러 티저: "상위 1% 궁합의 인연이 회원님을 조회했어요" → 해제 유료
- 보낸 신호 목록 · 나를 조회한 사람 전체 목록(구독 특전)

### ④ 피드 (P1)
- 고민상담(연애+사주) · 자유 · 셀소, 성별·익명 필터 (글램 동일)
- 사주 상담 수요 강한 여초 커뮤니티 성격 → 성비 방어 자산
- 초기: 역술 크리에이터 AMA·궁합 풀이 이벤트로 시딩

### ⑤ 마이
- 프로필: 사진 6장 · 자기소개 · 문답 5개 · 성향/라이프스타일 태그 (글램 구조 이식)
- 내 사주 정보: 출생시간 수정 2회 제한(조작 방지), 수정 시 전체 재계산
- 인증 센터: 본인(필수)·직장·학교 — "인증 회원의 신호 수락률 n% 높아요"로 유도
- 스토어 · 미션 · 설정(연락처 기반 지인 차단)

## 3. 사주 엔진 · 매칭 정렬 정책

**입력 정책**
- 생년월일: PASS 본인인증 값 고정, 수정 불가
- 출생시간: 자가 입력, "모름" 허용 → 삼주(三柱) fallback
- 양력→만세력 변환→사주팔자 산출은 가입 시 1회 계산 후 캐시

**궁합 점수**
- 쌍 단위 단일 점수 0~100 + 상세 5요소: ①오행 상생·보완 ②일간 궁합 ③지지 합·충 ④띠 ⑤음양 균형
- 점수는 규칙 기반(결정론), 풀이 텍스트는 LLM 생성 — 분리해야 재현성·항의 대응 가능
- 양쪽 시주 보유 시 "정밀 궁합" 배지 / 미상 시 "정확도 75%" 표기
- 조회 시점 lazy 계산 + 캐시 (N² 사전계산 금지)

**정렬 정책 — 궁합은 정렬이지 필터가 아니다**
```
노출 순위 = 궁합 0.5 × 활동성 0.2 × 프로필 완성도 0.2 × 거리 감쇠 0.1  (초기 가중치, A/B 조정)
```
- 하드 필터는 성별·나이·거리·차단뿐. 궁합 점수로 노출 차단 금지 (유동성 보호)
- 낮은 궁합은 "보완이 필요한 관계"로 프레이밍 → 보완 풀이 상품으로 연결

## 4. 재화 경제 — 엽전(가칭)

### 소모처
| 상품 | 가격 | 글램 대응 | 의도 |
|---|---:|---|---|
| 인연 신호 보내기 | 50 | 크러쉬 | 핵심 매칭 개시. 무료 유저 주 1회 페이스 |
| 상세 궁합 풀이 | 30 | (사주 특화) | 5요소 상세 + LLM 리포트 |
| 오늘의 인연 추가 열람 | 20 | 추천 추가 | 무료 3명 소진 후 |
| 블러 해제 | 60 | 조회자 확인 | 최고 마진 상품 |
| 부스트 (1시간) | 100 | 부스트 | 노출 가중 상승 |
| 보완 풀이 | 30 | (사주 특화) | 낮은 궁합 항의를 상품으로 전환 |

## 5. MVP 로드맵

| 단계 | 범위 | 완료 기준 |
|---|---|---|
| **P0 · MVP (~3개월)** | 가입(PASS 성인인증) → 사주 입력·만세력 → 프로필 → 궁합 정렬 카드덱 → 신호 → 매칭 → 채팅. 오늘의 운세(요약) + 엽전 기본 경제 + IAP. 신고·차단·사진 검수 | 가입→사주입력 85%↑, 첫 매칭 중위 48h |
| **P1 · 성장 (+3개월)** | 상세/보완 풀이(LLM), 블러 티저, 구독, 미션·리퍼럴, 지인 차단, 피드, 직장·학교 인증 | 유료 전환 5%↑, D7 20%↑ |
| **P2 · 확장 (+6개월)** | 결혼 프로필, AI 사주 리포트, 실시간 위치 근처, 시즌 운세 상품, 운세 단독 모드(피벗 대비) | 운세 단독 사용 비중 → 피벗 판단 |

- 도입하지 않는 것: 외모 티어·실물 랭킹, 평가 파밍, P0의 실시간 위치
- 권장 스택: Supabase(Auth·Postgres·Realtime 채팅·Edge Functions 궁합 계산) + React Native

## 6. 리스크 · 대응

| 리스크 | 내용 | 대응 |
|---|---|---|
| 출생시간 미상 | 다수 유저가 시(時)를 모름 | 삼주 fallback + 정확도 배지, "출생시간 찾는 법" 콘텐츠 |
| 허위 생년월일 | 궁합 신뢰 붕괴 | PASS 인증값 고정. 출생시간만 2회 수정 |
| 낮은 궁합 항의 | 호감인데 40점 → 반발 | "보완 관계" 프레이밍 + 보완 풀이 상품화. 산식 결정론으로 방어 |
| 성비 | 데이팅 앱 남초 | 운세 마케팅은 2030 여성 유입에 유리 — 성비를 당길 유일한 채널 |
| 콜드스타트 | 초기 밀도 부족 | 운세 단독 가치 선제공 + 지역 순차 오픈 |
| 규제·심의 | 청소년 보호, 통신판매 | 성인 인증 필수, 7일 환불, 사진 사전 검수 |

## 7. KPI · 천장

- **North star**: 주간 상호 매칭 수
- 온보딩: 가입→사주 입력 완료율 85%+ / 리텐션: D7 20% / 수익: 전환 5~8%, ARPPU 월 ₩25,000
- **1차 천장**: 국내 데이팅 결제 시장(수천억, 글램·위피·아만다·틴더 과점)의 니치 한 자릿수 % — 연 결제액 백억대 초반
- **구조적 한계**: 사주는 문화 종속(글로벌 확장 불가), 유입 훅이지 매칭 품질의 엔진이 아님 — 전환은 사진·밀도가 지배
- **천장 돌파**: 정체 시 역방향 피벗 — 운세 앱(포스텔러류 MAU 수백만 검증)에 데이팅 얹기. P2 운세 단독 모드가 그 장치
