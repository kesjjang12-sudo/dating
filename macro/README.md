# 간단 그리드 매크로 (테스트용)

화면의 맵 영역을 격자로 나눠 지그재그로 골고루 돌아다니면서, 각 지점에서 버튼을 2번씩 눌러주는 매크로입니다.

## 설치 / 실행 (본인 PC에서)

```bash
pip install pyautogui
python macro.py
```

실행하면 5초 카운트다운이 뜹니다. 그 사이에 대상 창(게임/앱)을 클릭해서 활성화해 두세요.

## 중지 방법

- 마우스를 **화면 왼쪽 위 구석(0,0)** 으로 확 밀면 즉시 멈춥니다 (pyautogui failsafe).
- 터미널에서 `Ctrl+C`로도 종료됩니다.

## 설정 바꾸기

`macro.py` 상단의 설정 블록만 고치면 됩니다.

| 설정 | 의미 | 기본값 |
|---|---|---|
| `REGION` | 맵 영역 `(x, y, 너비, 높이)`. `None`이면 화면 전체 | `None` |
| `ROWS`, `COLS` | 격자 크기 (방문 지점 수 = ROWS×COLS) | 4×4 |
| `ACTION` | `"click"`(마우스 클릭) 또는 키 이름 (`"space"`, `"f"` 등) | `"click"` |
| `PRESSES` | 지점마다 누르는 횟수 | 2 |
| `LOOPS` | 맵을 도는 바퀴 수, `0`이면 무한 반복 | 1 |
| `MOVE_DURATION` | 지점 간 이동 시간(초) | 0.4 |

맵 영역 좌표를 모를 때는 파이썬에서 `import pyautogui; pyautogui.displayMousePosition()`을 실행하고 마우스를 맵 모서리에 올려 좌표를 읽으면 됩니다.

## 참고

- 개인 테스트 용도입니다. 일부 게임은 약관상 매크로를 금지하거나 안티치트가 합성 입력을 차단할 수 있습니다.
- Windows에서 대상 프로그램이 관리자 권한으로 실행 중이면, 매크로도 관리자 권한 터미널에서 실행해야 입력이 들어갑니다.
